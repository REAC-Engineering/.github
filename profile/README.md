# REAC - Reverse Engineering · Automatic Coding

We're a software company based in Albania. We take existing systems apart, figure out what they really do, and rebuild them as clean, maintainable software. We also design and build new products for teams that need them done properly.

## What we do

- **Legacy system modernization**: we reverse-engineer old codebases and databases, document the business logic hidden inside them, and migrate them to modern stacks without losing what works.
- **Custom software development**: web apps, internal tools and business systems designed around how your team actually operates.
- **IT consulting**: architecture reviews, technology choices and practical guidance for businesses moving their operations onto software.

## How we work

- **Understand before rewriting.** Old systems encode years of decisions, so we map them before touching them.
- **Automate the repetitive parts.** Tooling and code generation handle the boilerplate so people can focus on the hard problems.
- **Ship in small steps.** Each change is incremental and testable, so nothing turns into a risky big-bang migration.
